# kyrsovay-gasstation-pochinsky

##Название проекта
Курсовая работа на тему: «Автозаправочная станция»

##Описание проекта
Программа автоматизирует основные операционные процессы автозаправочной станции (АЗС). Предназначена для операторов, сменных менеджеров и администраторов АЗС. Решает задачи учёта топлива, контроля работы колонок, фиксации инцидентов и формирования сменной отчётности.

##Технологии
Язык / платформа: C#, WPF

СУБД: MS SQL Server (SSMS)

##Инструменты: Visual Studio 2022, Git, .NET Framework 4.7.2
Как развернуть и запустить проект (инструкция «что куда нажать»)
Установить необходимое ПО
Установить Visual Studio Community (выбрать нагрузку «.NET Desktop Development»)

Установить SQL Server Management Studio (SSMS)

Развернуть базу данных
Открыть SSMS → подключиться к серверу (local)

Нажать кнопку «New Query»

Открыть файл database.sql из репозитория

Нажать кнопку «Execute» (зелёный треугольник)

Открыть проект в Visual Studio
Скачать репозиторий: нажать на GitHub «Code» → «Download ZIP» или выполнить git clone

Открыть файл StankiAccount.sln (в исходном проекте название файла, но по логике АЗС следует переименовать, например, FuelStation.sln) в Visual Studio

В файле App.config проверить строку подключения к БД:

text
Server=(local);Database=StankiDB;Trusted_Connection=True;
Нажать F5 или кнопку «Пуск» (зелёная стрелка)

##Работа с программой
После запуска откроется главное окно со списком топливораздаточных колонок (ТРК)

Чтобы добавить колонку: нажать кнопку «Добавить» → заполнить поля (инвентарный номер, модель, тип топлива, дата ввода в эксплуатацию) → нажать «Сохранить»

Чтобы зафиксировать инцидент: выбрать колонку из списка → нажать кнопку «Инциденты» → в открывшемся окне нажать «Новый инцидент» → заполнить дату, описание неисправности или разлива, степень критичности → нажать «Сохранить»

Чтобы посмотреть историю инцидентов по конкретной колонке: выбрать колонку → нажать «История» → откроется таблица со всеми зафиксированными событиями

Для формирования отчёта: в главном меню нажать «Отчёты» → выбрать период (день, неделя, месяц) → нажать «Сформировать» → отчёт (сменная сводка по отпуску топлива и инцидентам) откроется в отдельном окне с возможностью экспорта в Excel
